Baseline compare

A Shiny app for RNA-seq from mouse mutants with developmental delay
R Shiny
RNA-seq
Data Visualisation
DESeq2
ggplot2
Author

Richard White

Published

September 30, 2025

This is a Shiny app that I made to go along with a paper that we wrote in the Busch lab as part of the Deciphering the Mechanisms of Developmental Disorders project. You can try it out on shinyapps.io. The code is on github.

DMDD was a project to study embryonic-lethal mouse gene lines, to identify critical genes for embryo development and survival. Our part of the project was to analyse the RNA-seq data produced for each mutant line. One problem was that a significant portion of the lines were affected by developmental delay, which is a common issue. In these cases, the homozygous mutants appear much young than the wild-type and heterozygous siblings from the same litter (as assessed by somite number). This makes it difficult to determine whether genes are differentially expressed because of the effect of the mutation or because of the delay. We developed a procedure to try and mitigate this problem using a large RNA-seq dataset of wild-type embryos, covering the span of the ages of the embryos in the mutant lines.

To allow other people to use this baseline dataset to analyse their own mutant line RNA-seq data, I created a Shiny app.

The app accepts RNA-seq count data as two files, a count file and a sample file. The count file needs a columns for the gene identifiers and a column for the count data for each sample. The samples file contains metadata about each sample. The right-hand sidebar panel allows you to set various parameters and to start the analysis. There is a progress panel which prints the output from DESeq2 as the analysis can take some time.

The first thing it does is run a Principal Component Analysis (PCA) with the input data plus the baseline samples. This allows the user to check whether their data is compatible with the baseline. If the wild-type samples in the experimental data cluster significantly away from the baseline then this is analysis is not appropriate.

The PCA tab shows two plots. The first shows the experimental samples and only the baseline samples with matching somite stages. The second includes all the baseline samples

It then runs differential expression analysis using the DESeq2 package with three different sets of samples and model.

Analysis Set Samples DESeq2 model
Experiment Only Experimental Data only counts ~ (sex +) condition
Experiment + Baseline Experimental Data and stage-matched Baseline samples counts ~ (sex +) condition
Experiment + Baseline with Stage Experimental Data and stage-matched Baseline samples counts ~ (sex +) stage + condition

The differentially expressed (DE) genes are overlapped and specific subsets are assigned to 4 different categories of response as shown below.

The Results tab has buttons for each of the four results sets. Clicking the buttons shows a table of the DE genes for that set sorted by adjusted p value.

If you click on a row in the results table it takes you to the Count Plot tab which has an x-y scatter plot of the Normalised Counts for that gene in the experimental samples and the matching baseline samples. There is also a button to download a copy of the plot.
